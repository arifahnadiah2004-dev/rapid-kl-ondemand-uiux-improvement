# User Stories

1. As a Rapid KL On-Demand user, I want to view nearby pickup and drop-off locations on a clear map, so that I can easily identify and select suitable locations.

2. As a Rapid KL On-Demand user, I want to view the actual road route between my pickup and drop-off locations, so that I can better understand my journey.

3. As a Rapid KL On-Demand user, I want to receive more accurate estimated arrival times (ETA), so that I can plan my journey and manage my time effectively.
