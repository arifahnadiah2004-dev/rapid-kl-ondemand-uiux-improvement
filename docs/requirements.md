# Requirements

## Functional Requirements

| ID | Functional Requirements |
|---|---|
| FR1 | The system shall display the selected service zone and its boundaries on the booking map. |
| FR2 | The system shall allow passengers to select any pickup and drop-off location within the selected service zone. |
| FR3 | The system shall display the route between the selected pickup and drop-off points using actual roads. |
| FR4 | The system shall display a redesigned booking interface with clearly organised booking information. |
| FR5 | The system shall recommend suitable pickup locations using Agentic AI based on the passenger's current location. |
| FR6 | The system shall display booking details for passengers to review before confirmation. |


## Non-Functional Requirements

| ID | Type | Non-Functional Requirements |
|---|---|---|
| NFR1 | Performance | The system shall display the booking map within 3 seconds under a normal network connection. |
| NFR2 | Usability | The system shall allow passengers to complete pickup and drop-off selection within 3 minutes during usability testing. |
| NFR3 | Reliability | The system shall update the displayed route and pickup recommendations within 5 seconds after receiving new location information. |
| NFR4 | Security | The system shall require user authentication before allowing access to personal booking information. |
