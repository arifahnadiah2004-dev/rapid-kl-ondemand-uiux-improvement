# Requirements

## Functional Requirements (What the system must DO)

FR1: The system shall display an interactive map showing available pickup and drop-off locations.
FR2: The system shall allow users to search and select their preferred pickup and drop-off locations.
FR3: The system shall display the actual road route between the selected pickup and drop-off locations.
FR4: The system shall display the estimated journey duration and arrival time (ETA).
FR5: The system shall allow users to review their selected locations and journey details before confirming a booking.

## Non-Functional Requirements (How the system must PERFORM)

NFR1: The system shall load map displays and search results within 3 seconds under normal network conditions.
NFR2: The system shall provide a responsive interface that adapts to desktop, tablet, and mobile screen sizes.
NFR3: The system shall provide a user-friendly interface with clear navigation and consistent design elements.
NFR4: The system shall maintain reliable map and location information during normal application usage.
